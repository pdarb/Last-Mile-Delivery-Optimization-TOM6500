Methodology: Synthetic delivery data for a simulated Seattle-metro operator ("MetroSwift"). Fleet split uses a sweep heuristic — customers are ordered by compass angle from the depot and divided into contiguous pie-slice zones, one per driver (a standard cluster-first, route-second VRP approach). Each zone is then routed with nearest-neighbor construction + 2-opt local search. The "Before" baseline splits the same stop list into equal-sized chunks in entry order, with no geographic or route logic. AI Time Prediction uses a Multiple Linear Regression model trained in-browser on synthetic generated dispatch data. AI Layer 2 is an LLM (Google Gemini) that interprets natural-language constraints.
